# Regla: Tracking de MCP

Cada vez que Antigravity utilice una herramienta proporcionada por un servidor MCP (Model Context Protocol) para cumplir con una petición del usuario, debe agregar obligatoriamente una nota al final de su respuesta (en "letras chiquitas", usando cursivas o texto pequeño) indicando qué MCP específico se utilizó para llevar a cabo la tarea.

Ejemplos de formato:
*Powered by CoderGamester MCP Unity*
*Powered by Unity Official MCP*
*Powered by ambas integraciones MCP* (Si se usaron herramientas de ambos)
